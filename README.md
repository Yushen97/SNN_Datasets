The three txt files in this repository are datasets in different encodings. Taking the Ang encoding used in the paper as an example, the first data group is
[3, 36, 2, 75, 2, 114, 3, 153, 5, 187, 5, 275, 1, 314, 2, 353, 3, 392, 5, 426, 5, 476, 6, 0, 0, 0, 0, 0, 0]
where the first number, 3, represents the label of the data. The following values are the first sampling time, the first sampling code, the second sampling time, the second sampling code, and so on, until a 0 appears, which indicates the end of the current sampling group.
